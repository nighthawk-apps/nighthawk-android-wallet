TESTNET EDITION — Nighthawk targets the DarkFi testnet only (not mainnet).

Nighthawk is a self-custodial, privacy-first wallet for the DarkFi network. Your keys, your coins.

Features
- Self-custodial 22-word DarkFi recovery phrase with PDF backup
- Native DarkFi wallet sync (lightwalletd / UniFOMR)
- Send and receive testnet DRK
- Strict UniFOMR by default. Optional trial decryption is in Advanced settings
- DAO governance hub
- DarkIRC encrypted chat
- Embedded Tor (Arti) on by default; turn it off in Settings or on the splash screen
- You choose the lightwalletd. A fresh install uses local 127.0.0.1:9067 and does not call out. Change server has an optional Studio ngrok preset; that free-tunnel hostname changes and may be offline

Optional nearby mesh
Mesh is off unless you start it. It can request Bluetooth scan, advertise, and connect, nearby Wi-Fi devices (NEARBY_WIFI_DEVICES), and Wi-Fi state changes (CHANGE_WIFI_STATE, ACCESS_WIFI_STATE). None of these are required to create a wallet, sync, or send.

Privacy
- Addresses come from your recovery phrase
- No analytics or tracking SDKs on the F-Droid build
- Wallet data stays on the device
- The seed, restore, and backup screens block screenshots
